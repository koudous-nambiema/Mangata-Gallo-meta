## ✨ Features

- **Dynamic Cart Management**: Add products to cart, adjust quantities (+/-), remove items, and see real-time price calculations.
- **Live Inventory Updates**: Dynamic stock tracking that decrements available items upon checkout and automatically triggers a "SOLD OUT" badge when stock reaches zero.
- **Interactive Checkout Modal**: Order confirmation window providing immediate user feedback on purchase completion.
- **Cart Badge Indicator**: Dynamic header badge showing total item count in real time.
- **Responsive Design**: Mobile-first, adaptive grid layout tailored for mobile, tablet, and desktop viewports.
